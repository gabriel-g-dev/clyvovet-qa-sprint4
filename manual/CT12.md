# CT12 — Pet percorre criação, filtro, edição e exclusão

IDENTIFICAÇÃO: CT12 — Pet percorre criação, filtro, edição e exclusão

OBJETIVO: Exercitar o ciclo de vida de pet na API Java com leitura posterior.

RASTREABILIDADE: PBI #17 (https://dev.azure.com/clyvovet-fiap-2026-rm563298/ClyvoVet/_workitems/edit/17). Funcionalidade planejada na Sprint 1; regressão/validação no release Sprint 4, entrega 04/11/2026.

PRÉ-CONDIÇÕES: Java no commit c686580, H2 novo criado pelo Flyway; URL http://127.0.0.1:18080; navegador sem sessão. Não usar ambiente de produção. Executar cada caso em H2 novo, iniciado com -Duser.timezone=UTC; registrar D=AAAA-MM-DD UTC no início e calcular os deslocamentos uma vez. Para HTTP: Content-Type application/json; obter JWT próprio em POST /api/auth/login com {"email":"admin@clyvovet.com.br","senha":"admin123"} ou {"email":"gabriel@clyvovet.com.br","senha":"tutor123"}, conforme perfil do caso. Enviar Authorization: Bearer <token> apenas no cliente local; não registrar o token nas evidências.

ENTRADAS CONTROLADAS: JWT ADMIN; pet QA-CT12 com Cachorro/SRD/2023-01-15/12.50/tutorId=1; edição nome QA-CT12-editado e peso 13.25

SAÍDA ESPERADA: POST=201; GET confirma dados; filtro especie/cachorro inclui id; PUT=200 atualiza nome/peso; DELETE=204; GET posterior=404.

PASSOS:
1. POST /api/pets com o JSON indicado e guardar idQA.
   Esperado: 201 com idQA numérico.
2. GET /api/pets/{idQA} e GET /api/pets/especie/cachorro.
   Esperado: 200; nome QA-CT12; filtro inclui idQA.
3. PUT /api/pets/{idQA} com nome QA-CT12-editado e peso 13.25, demais dados iguais.
   Esperado: 200 com novo nome/peso.
4. DELETE /api/pets/{idQA} e repetir GET do id.
   Esperado: 204 seguido de 404; somente QA excluído.

CRITÉRIO DE APROVAÇÃO: Aprovar somente se todos os resultados de cada passo forem observados; qualquer divergência reprova o caso.

RESTAURAÇÃO: Descartar o H2 ao encerrar o processo. Não apagar dados fora do ambiente de QA.

EXECUÇÃO: Planejado. Execução manual não realizada. Resultados da automação, quando disponíveis, são evidências separadas.
